# Structures (Structs)

Exercises to group variables of different types using structs.

## Exercises

- **[1. Student Average:](./01_student.c)** Stores student details and calculates the average grade using a Student struct.
- **[2. Distance Between Points:](./02_point_2d.c)** Calculates the Euclidean distance between two 2D points stored as structs.
- **[3. Complex Numbers Addition:](./03_complex_number.c)** Adds two complex numbers represented as structs.
- **[4. Product Inventory:](./04_product_inventory.c)** Calculates the total inventory value for N products stored as Product structs.
- **[5. Date Validation:](./05_valid_date.c)** Validates a calendar date using a Date struct.
- **[6. Time Difference:](./06_time_difference.c)** Calculates the elapsed time in HH:MM:SS between two times using Time structs.
- **[7. Highest Salary:](./07_highest_salary.c)** Finds the employee with the highest salary from a list using an Employee struct.
- **[8. Fraction Multiplication:](./08_fraction_multiplication.c)** Multiplies two fractions represented as structs and simplifies the result.
- **[9. Contact Search:](./09_contact_search.c)** Searches for a contact by name in a list of Contact structs.
- **[10. Point in Rectangle:](./10_point_in_rectangle.c)** Checks if a point is inside a rectangle using Point and Rectangle structs.
