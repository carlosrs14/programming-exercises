# GUI

Exercises to learn graphical user interface (GUI) programming in C on Linux.

## Exercises

- **[1. Window:](./01_window.c)** Creating a simple window.
- **[2. Button:](./02_button.c)** Adding a button and handling clicks.
- **[3. Label:](./03_label.c)** Displaying and updating text labels.
- **[4. Text Input:](./04_text_input.c)** Reading text from input fields.
- **[5. Layout:](./05_layout.c)** Organizing widgets in grids or boxes.
- **[6. Personalized font:](./06_personalized_font.c)** Create and use a presonalizated font.
- **[7. Canvas Draw:](./07_canvas_draw.c)** Drawing shapes on a canvas.
- **[8. Menu:](./08_menu.c)** Creating menu bars and items.
- **[9. Dialog:](./09_dialog.c)** Showing popups and dialog windows.
- **[10. Calculator GUI:](./10_calculator_gui.c)** A simple GUI calculator app.
