# Pointers

Exercises to understand pointer arithmetic, pass by reference, and dynamic memory management.

## Exercises

- **[1. Swap by Reference:](./01_swap_pointers.c)** Swaps two integers using pointers.
- **[2. Sum Array with Pointers:](./02_array_sum.c)** Sums the elements of an array by traversing it using pointer arithmetic.
- **[3. Min and Max of Array:](./03_min_max.c)** Finds the minimum and maximum elements in an array, returning them via pointers.
- **[4. Reverse Array In-Place:](./04_reverse_array.c)** Reverses an array in-place using two pointers advancing from opposite ends.
- **[5. String Length:](./05_strlen_manual.c)** Calculates the length of a string by iterating with a pointer until the null terminator is reached.
- **[6. Copy String:](./06_strcpy_manual.c)** Copies a source string to a destination buffer using pointers.
- **[7. Count Vowels and Consonants:](./07_vowel_consonant_count.c)** Counts the vowels and consonants in a string using pointers.
- **[8. Search Element with Pointers:](./08_pointer_search.c)** Searches for an integer in an array and returns a pointer to it.
- **[9. Concatenate Strings:](./09_strcat_manual.c)** Concatenates two strings using pointers.
- **[10. Dynamic Array of Multiples:](./10_dynamic_array.c)** Dynamically allocates an array, fills it with multiples of a number, and frees the memory.
