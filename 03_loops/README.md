# Loops

Exercises to practice loops and repetition statements (for, while, do-while).

## Exercises

- **[1. Multiplication Table:](./01_multiplication_table.c)** Prints the multiplication table of a given number from 1 to 10.
- **[2. Factorial of a Number:](./02_factorial.c)** Calculates the factorial N! of a non-negative integer N iteratively.
- **[3. Fibonacci Sequence:](./03_fibonacci.c)** Prints the first N terms of the Fibonacci sequence.
- **[4. Primes in Range:](./04_prime_range.c)** Prints all prime numbers less than or equal to an integer N.
- **[5. Sum of Digits:](./05_digit_sum.c)** Sums the individual digits of an integer iteratively.
- **[6. Reverse a Number:](./06_reverse_number.c)** Reverses the digits of an integer, maintaining the sign.
- **[7. Count Digits:](./07_digit_count.c)** Counts how many digits make up an integer.
- **[8. Pyramid of Asterisks:](./08_asterisk_pyramid.c)** Draws a symmetric pyramid of asterisks of height N in the console.
- **[9. Greatest Common Divisor (GCD):](./09_gcd.c)** Calculates the GCD of two integers using the Euclidean algorithm.
- **[10. Perfect Number:](./10_perfect_number.c)** Determines if an integer is equal to the sum of its proper positive divisors.
