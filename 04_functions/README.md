# Functions

Exercises to practice modularizing code by writing and utilizing functions.

## Exercises

- **[1. Happy new year:](./01_new_year.c)** Count 10 to 0 and print happy new year.
- **[2. Areas of Shapes:](./02_shapes_area.c)** Calculates the area of a square, rectangle, or triangle using separate helper functions.
- **[3. Next Prime:](./03_next_prime.c)** Finds the smallest prime number strictly greater than N using an is_prime helper function.
- **[4. Decimal to Binary:](./04_binary_conversion.c)** Converts a decimal number to its binary representation.
- **[5. Power Function:](./05_power.c)** Calculates the power of a base float to an integer exponent without using math.h.
- **[6. Least Common Multiple (LCM):](./06_lcm.c)** Calculates the LCM of two integers using helper functions for GCD and LCM.
- **[7. Digit at Position K:](./07_digit_at_position.c)** Returns the digit at the K-th position from right to left of an integer N.
- **[8. Range Sum:](./08_range_sum.c)** Returns the sum of all integers in the closed range [a, b].
- **[9. Count Leap Years in Range:](./09_leap_years_count.c)** Counts how many leap years exist in an inclusive range of years.
- **[10. Combinations C(n, k):](./10_combinations.c)** Calculates combinations C(n, k) = n! / (k! * (n-k)!) using a helper factorial function.
