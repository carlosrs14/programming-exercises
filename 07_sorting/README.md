# Sorting

Classical algorithms to sort numeric arrays in C.

## Exercises

- **[1. Bubble Sort:](./01_bubble_sort.c)** Implements the classical bubble sort algorithm iteratively.
- **[2. Selection Sort:](./02_selection_sort.c)** Repeatedly finds the minimum element and places it at the correct index.
- **[3. Insertion Sort:](./03_insertion_sort.c)** Inserts each element into its sorted position relative to preceding elements.
- **[4. Merge Sort:](./04_merge_sort.c)** A recursive divide-and-conquer algorithm that halves the array, sorts, and merges.
- **[5. Quick Sort:](./05_quick_sort.c)** Partitions the array based on a pivot and recursively sorts the sub-arrays.
