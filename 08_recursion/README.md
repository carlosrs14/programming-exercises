# Recursion

Exercises solved recursively in C.

## Exercises

- **[1. Recursive Factorial:](./01_factorial_recursive.c)** Calculates the factorial of a non-negative integer N recursively.
- **[2. Recursive Fibonacci:](./02_fibonacci_recursive.c)** Finds the N-th term of the Fibonacci sequence using recursion.
- **[3. Towers of Hanoi:](./03_towers_of_hanoi.c)** Solves the Towers of Hanoi puzzle for N disks.
- **[4. Recursive Binary Search:](./04_binary_search_recursive.c)** Searches for an element in a sorted array by recursively halving the search space.
- **[5. Recursive Digit Sum:](./05_digit_sum_recursive.c)** Calculates the sum of digits of an integer recursively.
